ನಮಸ್ಕಾರ ಸ್ನೇಹಿತರೇ!

AI ಕ್ಷೇತ್ರದಲ್ಲಿ ಪ್ರತಿದಿನವೂ ಹೊಸ ಹೊಸ ಬೆಳವಣಿಗೆಗಳು ನಡೆಯುತ್ತಿವೆ. ಆದರೆ ಇತ್ತೀಚಿನ ಕೆಲವು ಬೆಳವಣಿಗೆಗಳು AI ಮಾತ್ರವಲ್ಲ, Cybersecurity ಮೇಲೂ ದೊಡ್ಡ ಪರಿಣಾಮ ಬೀರುವ ಸಾಧ್ಯತೆ ಇದೆ.

ಇವತ್ತು ಅಂತಹ ಕೆಲವು ಪ್ರಮುಖ AI ಸುದ್ದಿಗಳನ್ನು ಸರಳವಾಗಿ ನೋಡೋಣ.

ಮೊದಲಿಗೆ Cybersecurity ಬಗ್ಗೆ.

Anthropic ನಡೆಸಿದ ಇತ್ತೀಚಿನ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ, GLM-5.3 ಎಂಬ open-weight AI model ನ cyber capabilities ಅನ್ನು ಪರೀಕ್ಷಿಸಲಾಗಿದೆ.

ಈ model, Anthropicನ closed model ಆಗಿರುವ Claude Mythosಗೆ ಬಹಳ ಹತ್ತಿರದ ಮಟ್ಟದ performance ತೋರಿಸಿದೆ.

ಉದಾಹರಣೆಗೆ, ExploitBench ಎಂಬ benchmarkನ ಕೆಲವು tasksನಲ್ಲಿ, ಒಂದೇ ರೀತಿಯ token ಬಳಕೆಯೊಂದಿಗೆ GLM-5.3 ಸುಮಾರು 12% ಪ್ರಯತ್ನಗಳಲ್ಲಿ vulnerabilities ಅನ್ನು exploit ಮಾಡಲು ಯಶಸ್ವಿಯಾಯಿತು.

Claude Mythos ಸುಮಾರು 14% success rate ತೋರಿಸಿತು.

ಅಂದರೆ, powerful cybersecurity capabilities ಈಗ ಕೇವಲ ಕೆಲವು ದೊಡ್ಡ ಕಂಪನಿಗಳ modelsಗೆ ಮಾತ್ರ ಸೀಮಿತವಾಗಿಲ್ಲ.

Open-weight models ಕೂಡ ವೇಗವಾಗಿ ಆ ಮಟ್ಟಕ್ಕೆ ಬರುತ್ತಿವೆ.

ಇದರಲ್ಲಿ ಒಳ್ಳೆಯ ವಿಷಯ ಏನೆಂದರೆ, Cybersecurity defenders ಕೂಡ ಇಂತಹ powerful AI models ಅನ್ನು vulnerabilities ಹುಡುಕಲು ಮತ್ತು systems ಅನ್ನು secure ಮಾಡಲು ಬಳಸಬಹುದು.

ಆದರೆ ಸಮಸ್ಯೆಯೂ ಇದೆ.

Attackers ಕೂಡ ಇದೇ ರೀತಿಯ technology ಬಳಸಬಹುದು.

ಮತ್ತೊಂದು interesting point ಏನೆಂದರೆ, vulnerability ಹುಡುಕುವ cost ಕೂಡ ಕಡಿಮೆಯಾಗುತ್ತಿದೆ.

Anthropic ಪ್ರಕಾರ, GLM-5.3-Flashಗೆ ಸುಮಾರು 20 ಡಾಲರ್‌ಗಳ token cost ಬಳಸಿ, Google Chromeನಲ್ಲಿ ಇತ್ತೀಚೆಗೆ ಬಹಿರಂಗವಾದ ಒಂದು vulnerability ಅನ್ನು ಪತ್ತೆಹಚ್ಚಲು ಸಾಧ್ಯವಾಯಿತು.

ಅಂದರೆ, advanced cyber attacks ಮಾಡುವ technology ಹೆಚ್ಚು accessible ಆಗುತ್ತಿದೆ.

ಹಾಗಾದರೆ AI ನಮ್ಮನ್ನು ಅಪಾಯಕ್ಕೆ ತಳ್ಳುತ್ತಿದೆಯಾ?

ಇಲ್ಲಿ ಒಂದು interesting comparison ಇದೆ — Aviation.

1919ರಲ್ಲಿ ವಿಮಾನ ಪ್ರಯಾಣದಲ್ಲಿ ಪ್ರತಿ ಸುಮಾರು 1,15,000 milesಗೆ ಒಬ್ಬ ವ್ಯಕ್ತಿ ಸಾವನ್ನಪ್ಪುತ್ತಿದ್ದ.

ಆದರೆ ಇಂದು aviation technology ತುಂಬಾ safer ಆಗಿದೆ.

ಈ safety ಹೇಗೆ ಬಂತು?

ಸಮಸ್ಯೆಗಳನ್ನು ಹುಡುಕುವುದು, ಅವುಗಳನ್ನು fix ಮಾಡುವುದು ಮತ್ತು ಮತ್ತೆ ಹೊಸ ಸಮಸ್ಯೆಗಳನ್ನು ಹುಡುಕುವುದು.

Software ಮತ್ತು AI safety ಕೂಡ ಇದೇ ರೀತಿಯಲ್ಲಿ improve ಮಾಡಬಹುದು.

AI systemsನಲ್ಲಿ security problem ಬಂದಾಗ, ಅದನ್ನು ಒಂದು failure ಅಂತ ಮಾತ್ರ ನೋಡದೆ, ಅದರಿಂದ ಕಲಿತು ಇನ್ನಷ್ಟು ಉತ್ತಮ safeguards ನಿರ್ಮಿಸಬೇಕು.

ಉದಾಹರಣೆಗೆ sandboxing, monitoring ಮತ್ತು security controlsಗಳನ್ನು ಇನ್ನಷ್ಟು ಬಲಪಡಿಸುವುದು.

ಇದರಿಂದ ಒಂದು ಮುಖ್ಯ lesson ಸಿಗುತ್ತದೆ:

AI technology ಎಷ್ಟು powerful ಆಗುತ್ತದೋ, ಅದಕ್ಕೆ ತಕ್ಕಂತೆ ನಮ್ಮ security engineering ಕೂಡ powerful ಆಗಬೇಕು.

ಮುಂದಿನ ಸುದ್ದಿ — Xiaomi ತನ್ನ ಹೊಸ MiMo-V2.6-Pro-RL model ಅನ್ನು ಬಿಡುಗಡೆ ಮಾಡಿದೆ.

ಈ model open-weight modelsಗಳಲ್ಲಿ Artificial Analysis Intelligence Indexನಲ್ಲಿ ಮೊದಲ ಸ್ಥಾನ ಪಡೆದುಕೊಂಡಿದೆ.

ಇದರ ವಿಶೇಷತೆ ಏನೆಂದರೆ, ಇದು text ಮಾತ್ರವಲ್ಲದೆ images, video ಮತ್ತು audio inputsನ್ನೂ handle ಮಾಡಬಹುದು.

ಇದರ context window ಬರೋಬ್ಬರಿ 1 million tokens.

ಅಂದರೆ, ಒಂದು model ಒಂದೇ ಸಮಯದಲ್ಲಿ ಬಹಳ ದೊಡ್ಡ ಪ್ರಮಾಣದ information ಅನ್ನು contextನಲ್ಲಿ ಇಟ್ಟುಕೊಂಡು ಕೆಲಸ ಮಾಡಬಹುದು.

MiMo-V2.6-Pro-RLನಲ್ಲಿ ಸುಮಾರು 1.02 trillion parameters ಇದ್ದು, ಪ್ರತಿಯೊಂದು tokenಗೆ ಸುಮಾರು 42 billion parameters active ಆಗುತ್ತವೆ.

Xiaomi model trainingನಲ್ಲಿ reinforcement learningಗೆ ತುಂಬಾ ಒತ್ತು ನೀಡಿದೆ.

ಒಟ್ಟು 7,000ಕ್ಕೂ ಹೆಚ್ಚು reinforcement-learning task environments ಮತ್ತು training code ಕೂಡ release ಮಾಡಲಾಗಿದೆ.

ಇಲ್ಲಿ ಮತ್ತೊಂದು interesting idea ಇದೆ.

ಒಂದು AI model code ಅನ್ನು run ಮಾಡಿಸಿ ಅದು ಕೆಲಸ ಮಾಡುತ್ತದೆಯೇ ಎಂದು ಮಾತ್ರ ನೋಡುವುದು ಸಾಕಾಗುವುದಿಲ್ಲ.

Code ಕೆಲಸ ಮಾಡಬಹುದು, ಆದರೆ ಅದು bad quality code ಆಗಿರಬಹುದು.

ಆದ್ದರಿಂದ Xiaomi coding attemptsನ qualityಯನ್ನೂ AI models ಬಳಸಿ evaluate ಮಾಡಿತು.

ಇದರ ಪರಿಣಾಮವಾಗಿ model ಹೆಚ್ಚು focused ಆಗಿ, ಅಗತ್ಯವಿರುವಷ್ಟು ಮಾತ್ರ changes ಮಾಡುವ code ಬರೆಯಲು ಕಲಿತಿತು.

ಇದು developersಗೆ ಒಂದು ದೊಡ್ಡ lesson:

“Code ಕೆಲಸ ಮಾಡುತ್ತಿದೆ” ಅಷ್ಟೇ ಸಾಕಾಗುವುದಿಲ್ಲ.

“Code maintainable ಮತ್ತು ಉತ್ತಮ qualityಯಲ್ಲಿದೆಯೇ?” ಅನ್ನುವುದೂ equally important.

ಮುಂದಿನ ದೊಡ್ಡ ಸುದ್ದಿ — Googleನ Gemini 3.8 Live.

Google ಎರಡು ಹೊಸ speech-to-speech AI models ಬಿಡುಗಡೆ ಮಾಡಿದೆ:

Gemini 3.8 Live ಮತ್ತು Gemini 3.8 Live Extended Thinking.

ಇವು text ಅನ್ನು ಮಾತ್ರ ಓದಿ ಉತ್ತರಿಸುವ models ಅಲ್ಲ.

ನೀವು AI ಜೊತೆ ನೇರವಾಗಿ ಮಾತನಾಡಬಹುದು.

Gemini 3.8 Live image ಮತ್ತು video inputsನ್ನೂ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬಹುದು ಮತ್ತು 97 languages support ಮಾಡುತ್ತದೆ.

ಅದರಲ್ಲೂ interesting ವಿಷಯ ಏನೆಂದರೆ, AI ನೀವು ಮಾತನಾಡುತ್ತಿರುವಾಗಲೇ tools ಮತ್ತು API calls ಅನ್ನು backgroundನಲ್ಲಿ ಬಳಸಬಹುದು.

ಅಂದರೆ, futureನಲ್ಲಿ AI ಜೊತೆ interaction ಇನ್ನಷ್ಟು natural ಆಗಬಹುದು.

ನೀವು typing ಮಾಡುವ ಬದಲು AI ಜೊತೆ simply ಮಾತನಾಡಬಹುದು.

ನಿಮ್ಮ screenನಲ್ಲಿ ಏನಿದೆ ಎಂದು AIಗೆ ತೋರಿಸಿ, ಅದರ ಬಗ್ಗೆ real-timeನಲ್ಲಿ ಸಹಾಯ ಪಡೆಯಬಹುದು.

Gaming, web browsing, mobile apps ಮತ್ತು day-to-day tasksಗಳಲ್ಲಿ ಇದು ತುಂಬಾ useful ಆಗಬಹುದು.

ಮುಂದಿನ ಸುದ್ದಿ DeepSeekನಿಂದ.

DeepSeek-V4.1-Flash ಎಂಬ ಹೊಸ modelನಲ್ಲಿ DeepSeek ಒಂದು ದೊಡ್ಡ ಸಮಸ್ಯೆಯನ್ನು solve ಮಾಡಲು ಪ್ರಯತ್ನಿಸಿದೆ — long context ಅನ್ನು efficiently handle ಮಾಡುವುದು.

AI agent ಒಂದು tool call ಮಾಡಿದಾಗ, ಹಿಂದಿನ conversationನ ದೊಡ್ಡ ಭಾಗವನ್ನು ಮತ್ತೆ modelಗೆ ಕಳುಹಿಸಬೇಕಾಗುತ್ತದೆ.

Conversation ದೊಡ್ಡದಾದಂತೆ ಇದಕ್ಕೆ memory ಮತ್ತು computation cost ಹೆಚ್ಚಾಗುತ್ತದೆ.

DeepSeek ತನ್ನ ಹೊಸ architectureನಲ್ಲಿ ಈ context memoryಯನ್ನು ಹೆಚ್ಚು efficiently store ಮಾಡುವ ವಿಧಾನವನ್ನು ಬಳಸಿದೆ.

ಇದರ ಪರಿಣಾಮವಾಗಿ, V4.1-Flash ಒಂದು million-token context window ಅನ್ನು support ಮಾಡುತ್ತದೆ.

ಅದರ input cache ಪ್ರತಿ tokenಗೆ ಕೇವಲ ಸುಮಾರು 890 bytes ಆಗಿದೆ.

DeepSeek ಪ್ರಕಾರ, ಇದು ಹಿಂದಿನ V1 modelಗಿಂತ ಸುಮಾರು 437 ಪಟ್ಟು ಕಡಿಮೆ.

ಅಂದರೆ future AI agentsಗೆ long conversations ಮತ್ತು ದೊಡ್ಡ datasets ಅನ್ನು handle ಮಾಡುವುದು ಇನ್ನಷ್ಟು cheap ಮತ್ತು efficient ಆಗಬಹುದು.

ಕೊನೆಯದಾಗಿ ಒಂದು interesting research — AREX.

Beijing Academy of Artificial Intelligenceನ researchers ಒಂದು research agent system ನಿರ್ಮಿಸಿದ್ದಾರೆ.

ಸಾಮಾನ್ಯ AI agent ಒಂದು ಪ್ರಶ್ನೆಗೆ answer ಹುಡುಕುವಾಗ ಕೆಲವೊಮ್ಮೆ ಒಂದೇ ತಪ್ಪನ್ನು ಮತ್ತೆ ಮತ್ತೆ ಮಾಡಬಹುದು.

AREX system ಬೇರೆ ರೀತಿಯಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

ಮೊದಲು information ಹುಡುಕುತ್ತದೆ.

ನಂತರ ತನ್ನ answer ಅನ್ನು check ಮಾಡುತ್ತದೆ.

ಯಾವ ಭಾಗಕ್ಕೆ evidence ಇದೆ, ಯಾವ ಭಾಗ ಇನ್ನೂ prove ಆಗಿಲ್ಲ ಎಂದು ನೋಡುತ್ತದೆ.

ಅದಾದ ಮೇಲೆ missing informationಗಾಗಿ ಮತ್ತೆ targeted search ಮಾಡುತ್ತದೆ.

ಅಂದರೆ,

Search → Check → Find the gaps → Search again → Improve the answer.

ಈ ರೀತಿಯ iterative approachನಿಂದ research tasksನಲ್ಲಿ performance ಉತ್ತಮವಾಗಿದೆ.

ಇಲ್ಲಿ ನಮಗೆ ಸಿಗುವ ದೊಡ್ಡ lesson ಏನೆಂದರೆ:

AI agent ಮಾಡುತ್ತಿರುವ ಪ್ರತಿಯೊಂದು step equally important ಅಲ್ಲ.

ಸರಿಯಾದ ಸಮಯದಲ್ಲಿ ಸರಿಯಾದ decision ತೆಗೆದುಕೊಳ್ಳುವ moments ತುಂಬಾ ಮುಖ್ಯ.

ಅದನ್ನು AIಗೆ ಕಲಿಸಿದರೆ, ಕಡಿಮೆ resources ಬಳಸಿ ಕೂಡ better results ಪಡೆಯಬಹುದು.

ಒಟ್ಟಿನಲ್ಲಿ ನೋಡಿದರೆ, AI ಕ್ಷೇತ್ರದಲ್ಲಿ ಈಗ ಮೂರು ದೊಡ್ಡ trends ಕಾಣಿಸುತ್ತಿವೆ.

ಒಂದು — Open-weight models ಇನ್ನಷ್ಟು powerful ಆಗುತ್ತಿವೆ.

ಎರಡು — AI models text ಮಾತ್ರವಲ್ಲದೆ voice, image ಮತ್ತು video ಜೊತೆ real-timeನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತಿವೆ.

ಮೂರು — AI agents ತಮ್ಮ ಕೆಲಸವನ್ನು ತಾವೇ check ಮಾಡಿಕೊಂಡು, ತಪ್ಪುಗಳನ್ನು ಸರಿಪಡಿಸಿಕೊಂಡು, ಮತ್ತೆ ಪ್ರಯತ್ನಿಸುವತ್ತ ಸಾಗುತ್ತಿವೆ.

ಅದನ್ನು safe, reliable ಮತ್ತು useful ಆಗಿ ಬಳಸುವುದು ಇನ್ನೂ ಮುಖ್ಯ.
